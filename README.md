# Quiz App

A command-line quiz application built with Node.js that tests your knowledge across multiple categories.

# About

This was my first solo coding project, built as part of my journey transitioning into a software development career. I built it to practice real-world JavaScript concepts going beyond just tutorials.

# Features

- Multiple choice questions
- [X] categories: Science, History and Technology
- Score tracking saved to a local JSON file
- Interactive terminal prompts using @inquirer/prompts

# Technologies Used

- Node.js
- JavaScript (ES Modules)
- @inquirer/prompts
- File System (fs/promises)

# Installation

1. Clone the repository:
```bash
   git clone https://github.com/Barnabasv/quiz-app.git
```

2. Navigate into the project folder:
```bash
   cd quiz-app
```

3. Install dependencies:
```bash
   npm install
```

4. Run the app:
```bash
   node index.js
```
